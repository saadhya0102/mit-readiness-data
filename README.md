# MIT Readiness research pipeline

Source code for collecting, normalizing, and validating public-evidence research records. This public repository intentionally excludes person-level datasets, scraped pages, competition rosters, raw captures, and generated reports. Those files remain in the private source archive and local workspace, outside Git tracking.

The original project contained enrollment-related research records. Public-source observations are not admissions probabilities or causal evidence. Supply your own appropriately reviewed inputs before running the processing scripts. Scripts that expect omitted data cannot run from this source-only checkout alone.
